# Chartering Desk Documentation

Welcome to the Chartering Desk documentation. This guide provides comprehensive instructions for users, administrators, and developers of the Chartering Desk platform.

## Platform Overview
Chartering Desk is an intelligent chartering workflow platform that uses AI to parse emails, classify cargo and tonnage, and facilitate market collaboration through the Desk Network.

## Intended Users
- **Shipbrokers & Chartering Professionals:** Managing daily chartering communications, finding matching tonnage/cargo, and creating recaps.
- **Founders & Operators:** Managing platform usage, billing, and system health.
- **Administrators:** Deploying, configuring, and monitoring the infrastructure.
