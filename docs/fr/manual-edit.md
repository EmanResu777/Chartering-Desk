# Manual Edit

Users can manually audit and correct data extracted by the AI Email Parser.

## Editable Fields
- **Vessel Data:** Name, DWT, built, drafts, special notes.
- **Cargo Data:** Commodity, quantity, laycan, rates/freight, addcom/commissions.
- **Commercial Factors:** Additional negotiated fields.

## Network Sync Protocol
- Local saves update your personal Inbox.
- Desk Network sync pushes updates to items published in the Desk Network.
- Provides warnings on sync failures.
- Viewer restrictions guarantee only the item's verified owner can invoke manual edits.
