# Desk Network

The Desk Network acts as the collaborative hub for your chartering activities.

## Overview
Participants can share parsed structured items (Cargo / Tonnage) with the platform’s private broker network.

## Publishing
- Items parsed from emails or manually created can be published securely into the network.
- **My Shared Cargo / My Shared Tonnage:** Views dedicated to managing what you publish outward.
- **Revoke Visibility:** Unpublishing an item immediately removes it from the Network Feed.

## Permissions & Security
- **Owner:** Full rights to edit, update, delete, highlight, or withdraw the shared item.
- **Recipient/Viewer:** Can view the details, express interest, or initiate Hot Opp matches, but cannot overwrite, edit, or spoof the structured data belonging to the owner.

## Manual Edit & Sync
Manual edits made to the original parsed requirement will sync to the Network item if it is actively published. 

## Workflow
All interactions function seamlessly across desktop and mobile layouts for consistent on-the-go brokerage.
