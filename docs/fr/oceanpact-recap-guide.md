# OceanPact Recap Guide

Create, edit, and confirm standard fixture recaps.

## Recap Draft Creation
- Availability unlocks automatically once a negotiation is `dual_approved`.
- Populates an **OceanPact Fixture Recap template**.
- Auto-filled fields map parsed variables (e.g. vessel name, cargo, rate) dynamically.

## Collaborative Working Draft
- Single shared source recap for both the Cargo and Vessel sides via their respective Recap Drafts lists.
- Editable commercial, operational, and vessel fields.
- Versioning and Audit Trail automatically maintained.
- "Save Draft" updates the working copy securely.

## Broker-side Recap Confirmation
- Both the vessel participant and cargo participant can individually register confirmation.
- **Locked Recap:** Once BOTH sides confirm, the recap enters a locked, read-only state block further edits.
- *Principal approval disclaimer* is embedded explicitly, asserting no automatic external sending and no legal e-signature substitution natively.

## Document Export
- Generate polished **DOCX** and **PDF** exports displaying all commercial terms and real-time confirmation status for principals/offline review.
