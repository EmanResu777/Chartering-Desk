# OceanPact Recap 指南

## OceanPact Recap Draft (草稿创建)
- 使用 OceanPact template。
- 能够进行 recap draft creation。
- 具备 auto-filled fields 和 editable fields。
- 支持 shared source recap，且双方看到的是同样的 Recap 内容 (both sides see the same recap)。

## 确认与锁定
- 进行 平台内经纪方 Recap 确认 (Broker-side Recap Confirmation)。
- 确认后成为 locked recap。
- Principal approval disclaimer 表明最终需要船东/租家审批。
- 不自动对外发送 (no automatic external sending)。
- 不提供法律电子签名 (no legal e-signature)。

## 导出
- 支持 DOCX export 和 PDF export。
- confirmation status in export 会被体现。
