# 诊断与故障排除

## 常见处理办法
- **Gmail button does nothing (Gmail按钮无反应):** 设置错误。
- **OAuth redirect/callback mismatch:** URI 回调不匹配。
- **email sync stuck:** 邮件同步卡死。
- **no relevant emails found:** 未发现相关邮件。
- **urgent item not visible:** 紧急项不可见，由于过期取消。
- **mobile bottom sheet overlap:** 移动端底栏重叠。
- **no credits / 402:** 额度耗尽 / 402。
- **admin panel not visible:** 管理员面板不可见，检查权限。
- **Stripe checkout issue:** Stripe 结账问题。
- **webhook not updating plan:** webhook 未更新计划。
- **DOCX/PDF export issue:** DOCX/PDF 导出问题，查弹窗拦截。
- **Firestore permission denied:** Firestore 权限由于 owner/participant 控制被拒绝。
- **Cloud Run deployment issue:** 部署错误。
- **NODE_ENV production issue:** 需要设为 production 避免性能错误。
