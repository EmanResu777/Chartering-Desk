## 产品及法律边界
- **平台内经纪方 Recap 确认 (Broker-side Recap Confirmation):** 平台内经纪方 Recap 确认 (Broker-side Recap Confirmation) 仅用于确认工作草稿内容。此确认既不是最终的固定包租合同 (not final fixture)，也不是最终的租船合同 (not final charter party)。
- **确认审批 (Principal Approvals):** 最终的船东、租船人及其他委托人的批准 (Principal / Owners / Charterers approval may still be required) 仍可能需要在平台之外进行。
- **无电子签名 (No legal e-signature):** 平台未实现任何具有法律约束力的电子签名 (no legally binding e-signature is implemented)。
- **无自动外部发送 (No automatic external sending):** 平台未实现自动向外部发送确认邮件的功能 (no automatic external recap sending is implemented)。
- **AI 限制 (AI Limitations):** AI 输出仅作为辅助工具，不是最终的法律或商业决定 (AI outputs are support tools, not final legal/commercial decisions)。
