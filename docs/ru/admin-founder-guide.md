# Руководство администратора / основателя

В этом руководстве описываются эксплуатационные и тестовые возможности, предоставляемые администраторам и основателям (founders).

## Режим администратора / основателя (Admin / Founder Mode)
Режим администратора автоматически включается для пользователей, чей UID или Email совпадает с параметрами `ADMIN_UIDS` или `ADMIN_EMAILS`, определенными в переменных окружения на стороне сервера.
- Проверяется на сервере для обеспечения безопасности.
- Администраторы игнорируют ограничения `402 Payment Required` (Безлимитное использование / admin bypass).

## Панель администратора (Admin Panel)
Панель доступна только проверенным администраторам и содержит:
- Мониторинг использования (Usage Monitoring)
- Мониторинг Stripe (Stripe Monitoring)
- Инструменты тестирования (Testing Tools)
- Журналы аудита (Audit Logs)

## Выдача тестовых кредитов (Granting Test Credits)
Администраторы могут предоставлять временные кредиты (test user grants) пользователям для тестирования функциональности ИИ.
- **Ограничение (Cap):** Допускается максимум 2 активных тестовых пользователя одновременно.
- **Срок действия (Expiry):** Выданные кредиты истекают автоматически (например, через 72 часа).
- **Отзыв кредитов (Revoke):** Администраторы могут вручную отзывать тестовые кредиты на панели управления.

## Системный аудит и чек-лист безопасного тестирования
- Все действия администратора (выдача/отзыв кредитов) фиксируются в коллекции Firestore `adminAudit`.
- Отслеживайте коллекцию `billing_audit`, чтобы выявлять непредвиденное поведение, связанное со статусом 402.
- Отслеживайте метрики сводки использования (Usage summary) для обнаружения аномалий.

## Чего НЕ СЛЕДУЕТ делать
- **Не отключайте** логику биллинга глобально (do not disable billing globally). Ограничьте тесты конкретными тестовыми пользователями.
- **Не раскрывайте (do not expose)** списки `ADMIN_EMAILS` или `ADMIN_UIDS` на стороне клиента.
- **Не создавайте** общие учетные записи администраторов / пароли; требуйте безопасных индивидуальных авторизаций.
