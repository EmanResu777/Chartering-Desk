# Биллинг и кредиты использования (Billing & Usage Credits)

Chartering Desk использует систему биллинга на основе кредитов для обеспечения защиты маржи (Margin Protection) при работе с ИИ-моделями.

## Система кредитов использования (Usage Credits System)
- **Цель:** Защита инфраструктуры от неограниченных затрат на ИИ-парсинг.
- **Экономика:** 
  - `creditsIncluded`: Базовое количество кредитов, включенное в ваш тарифный план.
  - `creditsUsed`: Количество кредитов, потраченное на успешные задачи парсинга за расчетный цикл.
  - `creditsRemaining`: Доступный остаток.
  - `resetAt`: Время обнуления и сброса счетчиков активных подписок.
- **402 CREDIT_LIMIT_EXCEEDED (Лимит превышен):** Как только использование превышает ваш лимит, задачи парсинга безопасно приостанавливаются.

## Тарифные планы
- **Trial / Solo / Desk / Enterprise**
- Планы предоставляют различные лимиты кредитов и доступ к определенному набору функционала.

## Идемпотентность и безопасность
- **Неудачные вызовы ИИ (Failed AI Calls):** Пользователи *не* штрафуются, и кредиты не списываются, если ИИ-парсинг завершается ошибкой (failed). Списание средств (deduction) происходит только после успешного сохранения результатов ИИ.
- **Идемпотентность:** Обновление биллинга использует атомарные инкременты, что исключает двойное списание средств (no double charge).

## Интеграция со Stripe
- **Оформление заказа (Stripe Checkout):** При повышении тарифа происходит безопасное перенаправление на страницу Stripe Checkout.
- **Биллинговый портал (Billing Portal):** Управление подписками осуществляется через портал для клиентов Stripe.
- **Webhook жизненного цикла Stripe:** Асинхронно обрабатывает события `checkout.session.completed`, `customer.subscription.updated` и `customer.subscription.deleted`, надежно обновляя статус биллинга пользователя (`billingStatus`: active, past_due, cancelled) в фоновом режиме на сервере.

## Исключения для администраторов
- Администраторы платформы (определяемые через переменные `ADMIN_EMAILS`/`ADMIN_UIDS`) используют внутренний обход лимитов (admin bypass), чтобы избежать блокировок при тестировании в production.
- Тестовые лимиты (test user grants) могут быть предоставлены ограниченному кругу тестовых учетных записей без необходимости активной подписки Stripe (тестовые лимиты не имитируют платную подписку).

## Исчерпание кредитов
- Что видят пользователи, когда кредиты заканчиваются: ИИ-парсинг временно приостанавливается, и пользователи получают уведомление "Payment Required" (Требуется оплата) с предложением перейти на биллинговый портал для повышения тарифа или дождаться окончания расчетного цикла.
