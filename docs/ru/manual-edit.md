# Ручное редактирование (Manual Edit)

Пользователи могут вручную проверять, корректировать значения и исправлять данные, извлеченные AI-парсером электронной почты (AI Email Parser).

## Редактируемые поля (Editable Fields)
- **Данные о судне (Vessel Data):** Название (Name), дедвейт (DWT), год постройки (built), осадка (drafts), специальные пометки/заметки (special notes).
- **Данные о грузе (Cargo Data):** Товар / груз (Commodity), количество (quantity), окна погрузки (laycan), ставки (rates/freight), комиссии / дополнительные комиссии (addcom/commissions).
- **Коммерческие факторы:** Второстепенные обсуждаемые поля.

## Протокол синхронизации сети (Network Sync Protocol)
- Локальное сохранение (Local save) обновляет ваш персональный список во Входящих (Inbox).
- Синхронизация Desk Network загружает и обновляет данные в элементы, опубликованные в Desk Network.
- Система выдает предупреждения в случае сбоя синхронизации (sync failure warning).
- Разрешения для просмотра (viewer restrictions) гарантируют, что только проверенный владелец (verified owner) данной позиции может инициировать редактирование.
