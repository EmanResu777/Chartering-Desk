# Синхронизация Gmail / электронной почты

Chartering Desk обеспечивает удобную интеграцию с Gmail с помощью API Google Workspace.

## Процесс подключения (Connection Flow)
При регистрации пользователи безопасно разрешают Chartering Desk индексировать недавние входящие сообщения с использованием процесса аутентификации Google OAuth.

## Очередь заданий синхронизации (Sync Job Queue)
Электронные письма управляются с помощью фоновых процессов (background processes).
- **Статусы заданий:**
   - `queued` (В очереди): Ожидает обработки.
   - `running` (Выполняется): В данный момент происходит запрос новых сообщений и их классификация.
   - `completed` (Завершено): Успешно синхронизировано.
   - `partial` (Частично): Произошли временные сбои, но задача была выполнена частично.
   - `failed` (Ошибка): Произошел сбой задачи (например, отозван токен).

## Особенности синхронизации
- **Опрос (Polling):** Фоновый воркер опрашивает очередь синхронизации через безопасные промежутки времени.
- **Баннер синхронизации (Sync Banner):** Визуальная индикация процесса на верхней панели, показывающая текущее состояние задания и счетчики (Scanned / Relevant / Skipped).
- **Безопасность токенов:** Токены Gmail OAuth *никогда* не хранятся на клиенте и не передаются клиентскому интерфейсу (no token exposure). Безопасные ошибки (safe errors) обрабатываются без риска утечки данных.

## Возможные проблемы (Common Issues)
- **Кнопка Gmail ничего не делает:** Убедитесь, что URI перенаправления OAuth верны в Google Cloud Console.
- **Несоответствие перенаправления OAuth:** Обычно это происходит, если URL-адрес абсолютно не соответствует действительным URI перенаправления (Redirect URIs).
- **Синхронизация длится слишком долго:** Возможно, процесс столкнулся с ограничениями (rate limits) или сбоями; система попытается провести согласование повторно.
- **Сбой обновления токена:** Зайдите в настройки, нажмите "Disconnect" (Отключить), а затем снова "Connect Gmail".
- **Не найдено релевантных писем:** Убедитесь, что в ваш почтовый ящик активно поступают рассылки и письма о фрахтовании.
