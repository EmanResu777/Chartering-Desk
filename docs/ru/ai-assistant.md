# ИИ-ассистент (AI Assistant)

Встраиваемый (inline) чат-бот для контекстной поддержки с использованием AI для облегчения рабочего процесса брокера.

## Цель (Purpose)
Интерфейс чата, напрямую интегрированный в контекст работы платформы.

## Использование
- Выполните запрос к ИИ для черновиков ответов (draft replies) на письма.
- Анализируйте риски, возникающие в связи с определенными пунктами (клаузулами – clauses) контрактов и рабочим состоянием судна.
- Оценивайте (примерные) расчеты фрахта (freight calc) или расчета тайм-чартерного эквивалента (TCE), если это применимо.

## Кредиты и Ограничения (Credits Usage & Limitations)
- Использование данного Ассистента предполагает потребление минимальных кредитов использования (minimal usage credits). ИИ умеет корректно обрабатывать ситуацию с возвращением кода 402 при их исчерпании.
- **Ограничения безопасности (Safe Limitations):** Наш интерфейс алгоритма не обладает полномочиями для окончательного коммерческого или юридического решения. Платформа платформы не дает гарантий (no guarantee) абсолютной точности ответов. Всегда проверяйте генерируемые черновики и вычисления.
