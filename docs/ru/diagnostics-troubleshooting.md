# Диагностика и устранение неполадок (Diagnostics & Troubleshooting)

Типичные разрешения проблем развертывания, операционных задач и затруднений пользователей.

## Состояние инфраструктуры (Infrastructure Health)
- Используйте конечные точки `/api/healthz` и `/api/readyz` для проверки работоспособности внутренних сервисов и состояния готовности.
- Прозрачность аудита (audit visibility) доступна исключительно администраторам.
- **Ошибки развертывания (Cloud Run Deployment Issues):** Часто связаны с ошибками компиляции / создания Docker контейнеров (container build errors) или отсутствующими переменными (missing configuration).
- **NODE_ENV=production:** Обязательно убедитесь в наличии этой переменной для оптимизированного функционирования (production issue / производительность).

## Типичные проблемы с интерфейсом
- **Кнопка Gmail ничего не делает:** Свидетельствует об отсутствии OAuth или неправильно настроенных доменах в консоли аутентификации от Google (Google Auth Console). Проверьте URL-перенаправлений (redirect URIs) или устраните проблемы с OAuth callback-кодом (OAuth callback issue).
- **Синхронизация электронной почты "зависла" (Email Sync Stuck):** Задание зависло в статусе `running` (выполняется); проверьте работу системы опроса (polling functionality).
- **ИИ-парсер пропускает слишком много писем:** Измените правила спам-фильтров; ИИ строго игнорирует запросы, не являющиеся чартерными, чтобы сохранить релевантность и лимиты кредитирования (strict relevance tuning).
- **Элемент "Urgent" (Срочно) не виден:** Либо истек срок действия позиции (expired), либо она была отключена (dismissed).
- **Перекрытие компонента мобильным интерфейсом (Bottom sheet mobile overlap):** Управляется безопасно через отступы (padding), удостоверьтесь в отсутствии ограничений браузера (browser limits) или параметров масштабирования (zoom).
- **Проблемы с макетом для мобильных устройств:** Интерфейс разрабатывался с учетом адаптации, обновите страницу, если область просмотра визуально «поехала» из-за сбоя (viewport glitches).
- **Пустой экран (Blank Screen):** Иногда бывает так, что сбой вызван крахом работы клиентской логики во фронтенд (severe frontend crash) или проблемами с сетевой загрузкой (network loading failure).

## Учетная запись / Доступ (Account / Access Issues)
- **Нет кредитов / 402 ошибка (No credits / 402):** Закончились кредиты. Обновите тарифный план в разделе Billing (Биллинг).
- **Панель администратора не отображается (Admin panel not visible):** Проверьте, соответствует ли рабочий идентификатор `UID` пользователя в настройках backend конфигурации `ADMIN_UIDS`.
- **В доступе Firestore отказано (Firestore Permission Denied):** Возникает из-за попыток просмотреть и/или прочесть файлы рекапов/постов других лиц. Базовые правила безопасности защищают конфиденциальность.
- **Ошибка экспорта DOCX / PDF:** Ошибки, связанные с экспортом, заставляет проверить блокировщики всплывающих окон в браузере (popup blockers).

## Интеграция Stripe (Stripe Integration Issues)
- **Ошибки оформления покупки в Stripe:** Проверьте секретную переменную окружения от Stripe (Stripe Secret).
- **Webhook не обновляет тарифный план (Webhook not updating plan):** Проверьте, в точности ли совпадает подпись секретной переменной `STRIPE_WEBHOOK_SECRET` с конфигурацией в панели Stripe Dashboard.
