# Развертывание и переменные окружения (Deployment & Environment)

Инструкции по управлению процессом развертывания (deployment), и чаще всего, запуску инфраструктур (infrastructure typically) в облаке Google Cloud Run.

## Правила построения архитектуры (Architecture Guidelines)
- Архитектура должна выполняться за счет встроенных (стандартных) параметров стартового сценария Node.js (`npm start`).
- Инфраструктура Cloud Run подключает автоматическую привязку портов в выделенный `PORT`.

## Обязательные переменные окружения (Mandatory Environment Variables)
Убедитесь в наличии внедренных обязательных переменных для хранения ключей / секретов в рабочих сборках деплоя платформы:
- `NODE_ENV=production`
- **Firebase:** Настройки ключей / стандартная конфигурация продукта (Standard project config keys)
- **Google OAuth / Аутентификация почты (Gmail OAuth):** URI перенаправления (Redirect URIs), клиентский ID (Client ID), секрет клиента (Secret)
- **Stripe:** Список ID стоимости / Price IDs (например, `STRIPE_PRICE_ID_SOLO`), секрет (Secret key), секрет Webhook'ов.
- **Администрирование (Admin Configuration):** Ключи безопасности / права (например, `ADMIN_UIDS`, `ADMIN_EMAILS`)
- **API Провайдеры ИИ (AI Provisioning):** Ключи провайдеров интеграции с ИИ.

## Проверка состояния (поступающие запросы) (Deployment Probes)
- Проверяйте состояния начального подключения / развертывания (startup health probes) вызовами `/api/healthz`, в то время как тестирование работоспособности и читабельности сервера совершается вызовом `/api/readyz`.

## Контрольный список при развертывании (Deployment Checklist)
1. Тщательно проверьте наличие обязательных переменных сборки.
2. Подтвердите процесс (завершения) окончательной компиляции (package build completion) и его результат.
3. Удостоверьтесь в отсутствии ошибок и корректном ходе процедур по загрузки (проверка состояния Docker контейнеров) при развертывании пакета (sequence).

## Распространенные проблемы во время выполнения запуска
- Отсутствующие переменные (бэкенда) / Blank env variables; приводит к потере связи определенных блоков платформы на сервере.
- Конфликты / фильтрация данных фаерволлом или ограничения по политике CORS.
